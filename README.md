# ماشین حساب وزن لوله DataDev — DataDev Pipe Weight Calculator (PWA)

وب‌اپ (PWA) و اپ اندروید/iOS آفلاین برای محاسبه‌ی **وزن، ضخامت دیواره، قطر داخلی و قیمت** لوله‌ها بر اساس جداول استاندارد.
بدون بک‌اند و بدون وابستگی — فقط HTML / CSS / JavaScript ماژولار.

- **۵ زبان:** فارسی، English، العربية، Türkçe، Deutsch (راست‌به‌چپ خودکار برای فارسی و عربی)
- **طراحی:** Neumorphism روشن با رنگ تأکیدی آبی (هم‌خانواده با طراحی تارنور نسخه‌ی ۳)
- **فونت‌ها (لوکال، همه با مجوز آزاد OFL):** Estedad (فارسی و عربی)، Inter (متن لاتین)، IBM Plex Mono (اعداد و جداول)
- **قیمت بدون واحد پول:** قیمت هر کیلو را با هر واحدی وارد کنید (ریال، تومان، دلار و …)؛ نتیجه با همان واحد است.
- **اپ موبایل:** اندروید و iOS با Capacitor — راهنمای ساخت و انتشار در [PUBLISHING.md](PUBLISHING.md)
- توسعه‌دهنده: **امیرحسین بساطی — DataDev**

## روش محاسبه

- **ضخامت لوله‌های پلاستیکی تحت فشار:** طبق ISO 4065 — `e = dn / (2S + 1)` با گرد کردن رو به بالا تا 0.1 mm.
- **وزن لوله‌های پلاستیکی:** با میانگین ضخامت دیواره (e + نصف تلرانس ISO 11922-1 grade V) — همان روش جداول DIN 8074/8077.
- **وزن لوله‌های فلزی:** با ضخامت اسمی — `W = π·(D − t)·t·ρ`.
- **قیمت:** `قیمت هر متر = وزن هر متر × قیمت هر کیلو` و `قیمت کل = قیمت هر متر × متراژ`.

وزن واقعی بسته به تولیدکننده ممکن است ۱ تا ۳٪ متفاوت باشد.

## به‌روزرسانی جداول

همه‌ی داده‌ها در `js/data.js` هستند و این فایل با اسکریپت زیر ساخته می‌شود. فایل `js/data.js` را دستی ویرایش نکنید؛ مقادیر را در اسکریپت تغییر دهید:

```bash
python3 tools/generate_data.py
```

بعد از هر تغییر در فایل‌ها، مقدار `VERSION` را در `sw.js` بالا ببرید تا کاربران نسخه‌ی جدید را بگیرند.

## اجرا

```bash
python3 -m http.server 8000   # یا: npx serve .
```

برای نصب روی موبایل از «Add to Home Screen» یا «Install App» مرورگر استفاده کنید.
