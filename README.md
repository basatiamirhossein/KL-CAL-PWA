# کبیرلوله — محاسبه‌گر قیمت لوله پلی‌اتیلن (PWA)

یک وب‌اپ تک‌صفحه‌ای و قابل‌نصب (PWA) برای محاسبه‌ی سریع قیمت لوله‌های پلی‌اتیلن PE80 و PE100، بر پایه‌ی جدول مشخصات فنی استاندارد **۱۴۴۲۷-۲** (ضخامت دیواره و وزن هر متر بر حسب قطر خارجی و فشار کاری). بدون بک‌اند، بدون وابستگی یا فریم‌ورک — فقط HTML/CSS/JS خام.

## نصب و اجرا

چون این پروژه یک PWA است (دارای Service Worker و Manifest)، برای اینکه حالت آفلاین و نصب‌پذیری درست کار کند باید از طریق یک سرور (حتی محلی) باز شود، نه مستقیم با باز کردن فایل:

```bash
npx serve .
```

سپس آدرس نمایش‌داده‌شده را در مرورگر باز کنید. برای نصب روی موبایل یا دسکتاپ، از گزینه‌ی «Add to Home Screen» یا «Install App» مرورگر استفاده کنید.

## نحوه‌ی استفاده

1. نوع ماده را انتخاب کنید: **PE80** یا **PE100**.
2. قیمت هر کیلوگرم (ریال) را وارد کنید.
3. قطر خارجی لوله (mm) و فشار کاری (bar) را انتخاب کنید.
4. متراژ لوله مورد نیاز را وارد کنید.
5. دکمه‌ی «محاسبه قیمت» را بزنید تا SDR، ضخامت، وزن هر متر، قیمت هر متر و قیمت کل نمایش داده شود.

اگر برای ترکیب انتخاب‌شده (قطر × فشار) در استاندارد مقداری تعریف نشده باشد، پیام خطای مناسب نمایش داده می‌شود.

## منبع داده و فرمول محاسبه

جدول `TABLES` در `index.html` برگرفته از جدول مشخصات فنی رسمی شرکت کبیرلوله (مطابق استاندارد ۱۴۴۲۷-۲) است و شامل ضخامت دیواره و وزن هر متر لوله برای هر ترکیب از نوع ماده، قطر خارجی و فشار کاری (SDR) می‌باشد.

```
قیمت هر متر = وزن هر متر (kg/m) × قیمت هر کیلو (ریال)
قیمت کل     = قیمت هر متر × متراژ (m)
```

> اگر استاندارد یا قیمت مواد اولیه تغییر کرد، فقط کافی است مقادیر جدول `TABLES` در ابتدای تگ `<script>` داخل `index.html` به‌روزرسانی شود.

## ساختار فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | کل اپ: ساختار صفحه، استایل و منطق محاسبه |
| `sw.js` | Service Worker — کش کردن فایل‌ها برای کارکرد آفلاین |
| `manifest.webmanifest` | مشخصات PWA (نام، آیکون‌ها، حالت standalone) |
| `favicon.png`, `apple-touch-icon-*.png` | آیکون‌های اپ برای مرورگر و صفحه‌ی اصلی موبایل |
